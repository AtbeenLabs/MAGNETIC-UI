UNDER THE SURFACE

HOW THE FIELD WORKS

This is an experiment in translating physical measurements into motion — with clear boundaries between measured data and interaction demos.

01
⌁

Measure

The browser reads X, Y and Z magnetic-field values from a supported device sensor, in microtesla (µT).

02
◎

Compare

A quiet-environment baseline is subtracted from each reading. The difference estimates how much the local field has changed.

03
✳

Map & move

Four directional calibration samples create an approximate screen-space mapping. A damped spring turns that vector into fluid UI motion.

!
Hardware reality check

A single magnetometer measures the local field vector; it does not directly measure a magnet's position or distance. Magnet polarity, device orientation, nearby metal, speakers, cases and sensor filtering can change the signal. Direction is an estimate, not a precise tracker. The browser API is experimental/limited and requires a secure context and permission.
